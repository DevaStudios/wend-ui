Button

Examples

With icons

Icon-only

States (primary)

Hover and Active are shown as static swatches here since they're pointer-driven pseudo-states — try the Default button above to see them live.

Usage

<wend-button variant="primary" label="Label"></wend-button>

Props

Property Attribute Description Type Default
disabled disabled Disables the button. boolean false
variant variant Visual style of the button. "primary" | "secondary" | "tertiary" | "destructive-primary" | "destructive-secondary" | "destructive-tertiary" 'primary'
label label The button's label text. Can be an empty string for an icon-only button. string ''
iconLeft icon-left Name of a wend-ui icon to render on the left of the label. string undefined
iconRight icon-right Name of a wend-ui icon to render on the right of the label. string undefined
iconOnly icon-only Renders a square, label-less button containing only icon-left. Ignores the label and icon-right. boolean false

Radio

Examples

Usage

<wend-radio name="group" value="a" label="Label"></wend-radio>

Props

Property Attribute Description Type Default
selected selected Whether the radio button is selected. boolean false
name name Name of the radio group this button belongs to. Radios sharing a name are mutually exclusive. string undefined
value value Value submitted for this radio button when part of a form. string undefined
label label The radio button's label text. Can be an empty string for a label-less radio button. string ''
disabled disabled Disables the radio button. boolean false

Radio Group

Examples

Usage

<wend-radio-group name="group" value="a" label="Label"> <wend-radio value="a" label="A"></wend-radio> <wend-radio value="b" label="B"></wend-radio> </wend-radio-group>

Props

Property Attribute Description Type Default
label label The group's label text. Can be an empty string for a label-less group. string ''
name name Name applied to every wend-radio child, so they act as one mutually-exclusive group. string undefined
value value Value of the currently selected radio in the group. string undefined
disabled disabled Disables every radio in the group. boolean false
