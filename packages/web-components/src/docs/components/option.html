Usage

<wend-select> <wend-option value="a">A</wend-option> <wend-option value="b">B</wend-option> </wend-select>

Props

Property Attribute Description Type Default
value value Value submitted for this option when selected by its parent wend-select. string undefined
selected selected Whether this option is the currently selected one. Set by the parent wend-select. boolean false
active active Whether this option is the keyboard-active one (highlighted, not necessarily selected). Set by the parent wend-select. boolean false
disabled disabled Disables this option, excluding it from selection and keyboard navigation. boolean false
