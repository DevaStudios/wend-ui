Radio

Examples

Usage

<wend-radio name="group" value="a" label="Label"></wend-radio>

Props

Property Attribute Description Type Default
selected selected Whether the radio button is selected. boolean false
name name Name of the radio group this button belongs to. Radios sharing a name are mutually exclusive. string undefined
value value Value submitted for this radio button when part of a form. string undefined
label label The radio button's label text. Can be an empty string for a label-less radio button. string ''
disabled disabled Disables the radio button. boolean false
