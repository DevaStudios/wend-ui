Basic usage

Load the component loader script and the base stylesheet, then use any wend-ui element directly in HTML:

<link rel="stylesheet" href="node_modules/@devastudios/styles/dist/index.css" />
<script type="module" src="node_modules/@devastudios/web-components/loader/index.js"></script>

<wend-button variant="primary" label="Click me"></wend-button>
